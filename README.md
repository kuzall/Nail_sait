# 💅 Angelina Nail Studio — Сайт, CRM и Telegram-бот

Комплексное digital-решение для студии ногтевого сервиса: продающий промо-сайт с онлайн-записью, встроенная мини-CRM система для мастера и Telegram-бот для мгновенных уведомлений и управления визитами.

---

## 🌟 Ключевые возможности

### 1. 🌐 Клиентский сайт (`index.html`)
- **Адаптивный дизайн**: продуманный интерфейс для смартфонов, планшетов и ПК.
- **Портфолио и услуги**: наглядный прайс-лист, фотогалерея выполненных работ и блок отзывов.
- **Интерактивная онлайн-запись**: пошаговый выбор процедуры, даты и свободного времени.
- **Защита от спама**: валидация имени, проверка корректности номеров телефонов.

### 2. 📊 Панель управления / CRM (`admin.html`)
- Авторизация мастера по паролю.
- Полный журнал записей клиентов с фильтрацией по статусам и датам.
- Статусы заявок: *Новая*, *Подтверждена*, *Выполнена*, *Отменена*.
- Быстрая связь с клиентом в один клик через мессенджеры (**MAX**, **WhatsApp**).

### 3. 🤖 Telegram-бот мастера (`bot.py`)
- Мгновенные уведомления о каждой новой записи с сайта.
- Интерактивные карточки: имя, номер телефона, выбранные услуги, дата и время.
- Кнопки быстрых действий для мастера прямо в чате Telegram.

### 4. ⚙️ Архитектура и надежность (`server.py`, `config.py`)
- Легковесный бэкенд на Python без избыточных тяжелых фреймворков.
- Хранение записей в локальной базе данных **SQLite**.
- Безопасная конфигурация: токены и пароли изолированы в `.env` и никогда не попадают в публичный доступ.

---

## 🛠️ Стек технологий

- **Frontend**: HTML5, Modern CSS3 (Flexbox/Grid, анимации), Vanilla JavaScript (ES6+)
- **Backend**: Python 3.10+, встроенный HTTP/REST API сервер, SQLite3
- **Bot**: `aiogram 3.x`, `asyncio`
- **Безопасность**: `.env` конфигурирование, валидация входящих запросов, санитайзинг данных

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/kuzall/angelina-nail-studio.git
cd angelina-nail-studio
```

### 2. Установка зависимостей для бота
```bash
pip install -r requirements.txt
# или напрямую:
pip install aiogram
```

### 3. Настройка переменных окружения
Скопируйте файл примера и укажите свои параметры:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```ini
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_ADMIN_ID=ваш_telegram_id
PORT=3000
ADMIN_PASSWORD=ваш_пароль_для_crm
```

### 4. Запуск проекта
Запуск веб-сервера и CRM:
```bash
python server.py
```
> Сайт будет доступен по адресу: `http://localhost:3000`  
> Панель мастера: `http://localhost:3000/admin.html`

Запуск Telegram-бота:
```bash
python bot.py
```
